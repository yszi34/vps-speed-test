## v.ps测速怎么测：官方三件套

V.PS 每个机房都提供三样官方测试工具：Looking Glass（路由追踪页）、speedtest 子域名、以及一个 100MB 测试文件。官方原话是 "Try before you buy"，这套测速体系本来就是给潜在买家用的，下单前完全不必靠猜。

具体用法分三步：

1. **打开 Looking Glass 页面**，跑 ping、traceroute 和 DNS lookup，看从机房到你的路由怎么走；
2. **用本地网络 ping 测试 IP**，测延迟和丢包；
3. **下载 100MB 测试文件**，测直连下载速度——这比 speedtest 网页更接近真实使用场景，因为它走的是机房到你家宽带的直连链路。

## 同城机房可能有两套网络，别测错

这是大多数测评文章没讲清的一点：V.PS 在部分城市运营**两张网络**，各配独立的官方 Looking Glass。法兰克福的 Cloud/Mini 套餐用 `fra-premium.lg.xtom.com`，Nano 套餐用 `fra.lg.xtom.com`；新加坡的 Performance 套餐用 `sin-premium.lg.xtom.com`，Edge 套餐用 `sin-edge.lg.xtom.com`——四个地址都支持 ping、traceroute 和测速。

## FAQ

**v.ps测速地址打不开或数据异常怎么办？**
先确认用对了地址——Nano 和 Storage 系列有独立测速点，法兰克福、新加坡各有两个 LG 区分网络。测速点本身偶尔维护，测不了可以先用测试 IP 在本地 ping。

**香港套餐能解锁 ChatGPT 或 Claude 吗？**
不能。2026 年 7 月的测评明确记录香港 IP 无法访问 Claude、Gemini 等服务，这是香港地区本身的限制。要解锁 AI 服务看悉尼（AS9929）、伦敦、新加坡、法兰克福 Performance 这些已升级的线路，多份测评都记录了 TikTok / Netflix / ChatGPT 解锁正常。

**移动宽带用户适合哪个机房？**
优先香港（回程移动 CMI 直连）或已升级 CMIN2 的 Performance 系列。大阪和美西机房的实测数据显示移动方向延迟高、丢包多，除非你的用途不敏感，否则别硬选。

**和专攻亚太线路的商家比，V.PS 适合谁？**
像 GoMami 这类只做亚太（香港/日本/新加坡/洛杉矶）、全线 CN2 + AS9929 + CMIN2 的商家，在中国方向线路专精度上更高；V.PS 的强项是全球 11 个机房、干净的 KVM 和大带宽（Performance 系列单机 1–2.5Gbps）。业务主要面向国内、预算敏感，亚太专精商家更对口；需要欧洲节点或全球分布，V.PS 更合适。
